# Top Corner Lab — Chinese Learning OS

A responsive, Apple-inspired Chinese study dashboard for HSK 5, HSK 6 and HSKK Advanced.

## Run locally
Open `index.html` in a modern browser. Study logs and checklist data are saved in that browser on that device.

## Install as an app (PWA)
For installation and offline caching, serve this folder over HTTPS (or localhost). Upload the folder contents to a static host such as GitHub Pages, Netlify, or Cloudflare Pages, then open the hosted URL on your phone and use the browser's **Add to Home Screen / Install App** option. `file://` opening supports the dashboard but not PWA installation.

## Data
Use **Export data** to download a JSON backup and **Import data** to restore it. Data is stored locally, not in a cloud account; it does not automatically sync across devices. Keep backups before clearing browser data.

## Study plan
17 hours per week:
- Reading: 5 hours
- Speaking: 4 hours
- Listening: 3 hours
- Writing: 3 hours
- Vocabulary and error review: 2 hours

The skill chart values are rough visual estimates based on the uploaded radar image, not official exam scores. Replace them with timed diagnostic test results as you gather evidence.
